# Contributing

Thank you for helping improve Textual Silicon. This is an independent community
project and is not affiliated with or supported by Codeux Software, LLC.

## Before opening an issue

- Search existing issues to avoid duplicates.
- Use the appropriate issue form and include the macOS version, Mac model or
  architecture, app version or commit, and clear reproduction steps.
- Do not post passwords, IRC credentials, license keys, private logs, or other
  sensitive information.

## Pull requests

1. Create a focused branch from the current default branch.
2. Keep each pull request limited to one logical change.
3. Follow the style of the surrounding Objective-C or Swift code.
4. Build the relevant scheme and run applicable tests before submitting.
5. Explain the motivation, implementation, and verification in the pull request.

By contributing, you agree that your contribution is distributed under the
licenses applicable to the files you modify. Retain existing copyright and
license notices.
