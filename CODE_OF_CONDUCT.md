# Code of Conduct

## Our standards

We are committed to a welcoming, respectful, and harassment-free community.
Examples of positive behavior include constructive feedback, empathy, respect
for differing viewpoints, and taking responsibility for mistakes.

Unacceptable behavior includes harassment, discriminatory or sexualized
language, personal attacks, trolling, threats, publishing another person's
private information, and conduct that would reasonably be considered
inappropriate in a professional setting.

## Scope and enforcement

This code applies in repository discussions, issues, pull requests, reviews,
and other spaces where someone represents this project. Project maintainers may
edit or remove contributions and may temporarily or permanently restrict
participation when behavior violates these standards.

Report conduct concerns privately to a repository maintainer through a contact
method listed on their GitHub profile. Reports will be reviewed promptly and
handled as confidentially as practical. Maintainers involved in a report must
recuse themselves from its resolution.
