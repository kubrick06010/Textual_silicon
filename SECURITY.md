# Security Policy

## Reporting a vulnerability

Do not disclose suspected vulnerabilities in a public issue. Use GitHub's
private vulnerability reporting feature on the Security tab when available.
If private reporting is unavailable, contact the repository owner privately
through a contact method listed on their GitHub profile.

Include affected versions or commits, reproduction steps, impact, and any
suggested mitigation. Never include real credentials, license keys, or private
user data. You should receive an acknowledgement as soon as a maintainer is
available to assess the report.

This independent project cannot provide security support on behalf of Codeux
Software, LLC or the original Textual project.
